# Reporting a vulnerability

If you have found a vulnerability in Light_torrent (for example, a torrent file or magnet link that
makes the app crash, write files to the wrong place or execute something; a spoofed update),
**please do not post it in public Issues**.

Report it privately: the **Security** tab of this repository → **Report a vulnerability**. Only the
developer will see your report.

Please include:
- the app version (Settings → at the bottom);
- steps to reproduce (you can attach the .torrent file or magnet link);
- what happened and what you expected.

I will reply as soon as I can; the fix will ship as an update that the app installs by itself.

Only the latest version is supported.
